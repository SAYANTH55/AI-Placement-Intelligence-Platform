# JobMode Roadmap

This document outlines the strategic vision and upcoming features for the JobMode platform. 
*Note: This roadmap is subject to change based on community feedback and contributions.*

## Q3 2026: Infrastructure & Scalability
- **[In Progress]** Dockerize the frontend and backend for production deployment.
- **[Planned]** Migrate from SQLite to PostgreSQL for production environments.
- **[Planned]** Set up comprehensive CI/CD pipelines using GitHub Actions.
- **[Planned]** Implement Redis for rate limiting and background task queues (Celery).

## Q4 2026: Enhanced Machine Learning
- **[Planned]** Retrain the `Profile Strength Index` using ground-truth placement outcomes.
- **[Planned]** Introduce RAG (Retrieval-Augmented Generation) for more accurate LLM candidate narratives.
- **[Planned]** Multi-lingual resume parsing support.

## Q1 2027: Enterprise Features
- **[Planned]** Single Sign-On (SSO) integration with University Identity Providers (SAML/OAuth).
- **[Planned]** Advanced analytics dashboards with custom exportable reports.
- **[Planned]** Automated email notifications for drive updates and application statuses.
