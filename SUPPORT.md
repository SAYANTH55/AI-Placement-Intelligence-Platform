# Support

Need help with JobMode? We've got you covered.

## 1. Documentation
Our primary source of support is our extensive documentation.
You can find architecture diagrams, deployment guides, and API schemas in the `/docs` directory.

## 2. GitHub Discussions
If you have questions about how to use the platform, or you want to discuss new features, you can open a thread in [GitHub Discussions](https://github.com/SAYANTH55/AI-Placement-Intelligence-Platform/discussions).

## 3. GitHub Issues
If you have found a reproducible bug or have a clear feature request, please open a [GitHub Issue](https://github.com/SAYANTH55/AI-Placement-Intelligence-Platform/issues) using the provided templates.

## 4. Community Support
Remember that JobMode is an open-source project maintained by volunteers. Please be respectful and patient when asking for help.
